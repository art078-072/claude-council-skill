# council — скилл для Claude Code

Консилиум перед ответом: защита от поддакивания.

LLM склонны соглашаться с пользователем — хвалить идею, подтверждать гипотезу, начинать ответ с «Ты абсолютно прав». Этот скилл заставляет Claude, прежде чем давать оценку, посмотреть на вопрос с нескольких противоположных позиций, столкнуть их в споре и только потом вынести вердикт — включая честное «Нет».

Идея взята из [karpathy/llm-council](https://github.com/karpathy/llm-council), где несколько независимых моделей отвечают на один вопрос и анонимно оценивают ответы друг друга. Здесь то же самое воспроизводится внутри одной модели через роли — без внешних API и дополнительных расходов.

## Установка

```bash
git clone https://github.com/art078-072/claude-council-skill.git /tmp/council
cp -r /tmp/council/council ~/.claude/skills/
rm -rf /tmp/council
```

Скилл станет доступен во всех проектах. Чтобы поставить его только в один проект, скопируйте папку `council` в `<проект>/.claude/skills/` вместо `~/.claude/skills/`.

Скиллы подхватываются при старте сессии — после установки откройте новую.

## Использование

Явный вызов:

```
/council оцени идею: подписка на доставку обедов в бизнес-центры
```

Скилл также подключается сам, когда вы спрашиваете мнение («что думаешь?», «стоит ли…», «проверь мой план»), просите обратную связь или предлагаете решение и ждёте согласия. На механических задачах (переименуй, отформатируй, выполни команду) и простых фактических вопросах он не срабатывает.

## Как это работает

Четыре роли высказываются независимо, затем спорят между собой, и Председатель сводит итог:

| Роль | Вопрос, на который отвечает |
|---|---|
| 🔴 Критик | Где это сломается? |
| 🟢 Адвокат | Почему это может сработать и при каких условиях? |
| 🔍 Ревьюер | Что здесь неточно, лишнее или чего не хватает? |
| ❓ Скептик | А правильный ли это вопрос? |

Вердикт всегда один из трёх: **Да / Да, но / Нет** — плюс список того, что менять в первую очередь.

Для коротких вопросов достаточно Критика и Адвоката. Для планов, стратегий, текстов и архитектуры работают все четыре, а при необходимости Председатель добавляет пятую роль-эксперта (юрист, финансист, безопасник).

## Правила, которые делают его рабочим

- Первое предложение ответа не может быть похвалой или согласием.
- Критик обязан найти хотя бы одну конкретную претензию — с цифрой, цитатой или номером строки.
- Вердикт «Нет» допустим и часто оказывается лучшим ответом.
- «Да, но» нельзя использовать, чтобы не говорить «Нет».

Полный текст — в [council/SKILL.md](council/SKILL.md).

## Ограничения

Это инструкция, а не гарантия. На простых вопросах модель иногда отвечает напрямую, минуя консилиум — в таком случае добавьте `/council` в начало сообщения. Скилл улучшает структуру рассуждения, но не добавляет модели знаний: цифры и факты в разборе всё равно нужно проверять.
